# 青简第三版便携包使用说明

日期：2026-10-20。版本标识：`custom3-portable1`。适用于 Windows 10 1809 及以上的 x64 系统，保留第三版全部外观与候选交互修改。

## 这份便携包能做什么

程序和词库从解压目录运行，无需运行安装向导，也不复制到 Program Files，不创建开始菜单或开机启动项。配置、学习记录和自定义主题保存在程序同目录的 `userdata` 文件夹，可随整个文件夹备份。

它仍是 Windows TSF 输入法，首次使用需要管理员注册 COM、输入法配置与类别；停用时需要注销。这个要求来自输入法接入方式，参见微软的[文本服务注册说明](https://learn.microsoft.com/en-us/windows/win32/tsf/text-service-registration)。因此它是“免安装向导的解压版”，不属于免管理员、零注册或完全无痕的软件。

## 第一次使用

1. 完整解压 ZIP 到固定的、本机可写 NTFS 文件夹，例如 `D:\Apps\Qingjian-portable`。不要从 ZIP 内直接运行，也不要放到 Program Files、网络共享或同步中的目录。
2. 如果电脑已有青简安装版或另一份便携版，先按下文备份和停用。脚本发现其他目录的注册会停止，不覆盖旧注册。
3. 双击 `Enable.cmd`，允许管理员权限，完成输入法注册。这一步不会启动管理员权限的输入法服务。
4. 以普通权限双击 `Start.cmd`，再用 `Win + Space` 切换到青简。若输入法列表没有刷新，请注销后重新登录，再运行 `Start.cmd`。
5. 双击 `Settings.cmd` 打开设置。所需样式在「外观」页；中英文固定间距在「译文排布」中选择。

已启用后，一般不必每次重新注册。登录后可手动运行 `Start.cmd`；普通桌面应用也可能在需要时自动拉起服务，但部分系统界面不能自动拉起，因此建议先运行启动脚本。

## 从已有安装版迁移


1. 保存正在输入的内容，切换到其他输入法，关闭青简设置。
2. 备份 `%APPDATA%\Qingjian`。这是原安装版的配置和学习数据目录，不是程序安装目录。保留独立备份，直到确认迁移成功。
3. 通过原安装版的卸载程序卸载青简，再注销或重启。原版卸载设计会保留用户数据，但仍应先备份。
4. 将备份目录**里面的内容**复制到便携包的 `userdata`，使配置路径为 `userdata\config.toml`，不要套成 `userdata\Qingjian\config.toml`。不迁移时会使用默认配置。
5. 按第一次使用的步骤启用和启动。

配置中若引用了包外的绝对路径，需要按新位置调整。便携包本身不包含任何个人配置、密钥或学习数据；迁移后的 `userdata` 可能含云服务密钥和输入记录，不应随意分享整个文件夹。

## 脚本说明

| 文件 | 用途 | 权限 |
|---|---|---|
| `Enable.cmd` | 检查文件和冲突，设置程序资源读取权限，注册 64 位、32 位 DLL | 会请求管理员权限 |
| `Start.cmd` | 检查当前注册后启动本目录的输入法服务 | 普通权限 |
| `Settings.cmd` | 打开本目录的设置程序 | 普通权限 |
| `Status.cmd` | 查看程序目录、数据目录和现有青简注册 | 只读，不要求管理员 |
| `Disable.cmd` | 只注销本目录对应的注册，并关闭本目录的服务；保留 userdata | 会请求管理员权限 |

启用过程中任一位数的注册失败，会尝试撤销本包的部分注册。出现其他目录的青简注册时，启用和停用均拒绝继续，避免误操作别的版本。若原目录已经被移动，应先恢复到原路径运行其停用脚本。

## 移动、换电脑或删除

先保存内容、切换到其他输入法，并关闭设置，然后运行 `Disable.cmd`。注销或重启后，再移动或删除文件夹，避免 DLL 仍被打开的应用占用。

移动到新路径或另一台电脑后，需要重新运行 `Enable.cmd`，因为 Windows 登记的是 DLL 的完整路径。新电脑也需要管理员权限。启用期间不要改目录名或拔出所在磁盘。

不建议将它当作可以随时拔出的 U 盘输入法。最稳妥的使用方式是把整个文件夹复制到目标电脑本地，启用后保持路径不变。

## 保存位置和系统改动

- `userdata`：配置、密钥文件、词频学习、生词与统计、输入日志、自定义主题和词库等用户数据。
- `data`、`assets`：随包词库、模型和资源。
- `qingjian-portable.txt`：便携模式标记。不要删除，否则程序会恢复读取 `%APPDATA%\Qingjian`。
- `%LOCALAPPDATA%\Qingjian\logs`：运行诊断日志，保持原位置，方便宿主应用中的 TSF DLL 写日志。
- `%ProgramData%\Qingjian\qingjian.ico`：注册时使用的系统输入法图标；正常注销会移除该图标。
- Windows 注册表：COM DLL 路径、TSF 输入法配置及类别。停用脚本执行注销，系统可能仍保留日志或缓存，因此不承诺零痕迹。

不创建自启动项或卸载项目。可用 `Status.cmd` 查询注册；取消使用时应运行 `Disable.cmd`，不能只删除文件夹。

## 验证范围与限制

已对便携目录识别、标记存在／缺失、移动路径及宿主进程隔离进行测试，并检查脚本语法、路径归属保护、打包文件和压缩包完整性。正式设置程序使用独立测试目录验证便携配置读取。

未在本机执行便携版的注册、注销、安装版卸载或应用内输入实测，以保留当前可用的安装版。包未签名，uiAccess 关闭，部分系统界面的候选窗口仍可能被遮挡。

第三版的字体、颜色、留白、倒序方向键、固定中英文间距和词性后置功能保持不变。后续验证重点是：注册后能否切换输入法、不同应用中的输入、32 位程序兼容，以及停用后系统列表是否刷新。
